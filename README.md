# 🤖 AI Expense Tracker & Meeting Assistant

An intelligent productivity application that helps users manage **expenses** and **meeting schedules** using natural language. Simply chat with the AI, and it automatically understands, organizes, and stores your data—no manual forms required.

## ✨ Features

* 💬 **AI Chat Interface** for effortless data entry
* 💰 Track expenses with simple messages like:

  * *"Spent 500 on coffee"*
  * *"Paid 1200 for groceries"*
* 🤖 Automatic extraction of amount, category, description, and date
* 📅 Schedule meetings using natural language
* 👤 Store meeting details, including **name, email, date, and time**
* 🔍 Instantly retrieve information through AI chat

  * *"How much did I spend this month?"*
  * *"Show my upcoming meetings."*
  * *"What's John's email?"*
* 📊 Dashboard with expense summaries and upcoming meetings
* 🔐 Secure authentication with protected user data
